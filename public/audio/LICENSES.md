# Audio sources and licences

Everything under `public/audio/` is generated by the scripts in `docs/brand/audio/`
(see the README there to regenerate). No third-party recordings or sample packs are used.

## Voice lines (`vo/*.m4a`)

- **Speech synthesis:** Qwen3-TTS (Alibaba Qwen team):
  - `Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign` (https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign)
    made one reference take per character from a text description;
  - `Qwen/Qwen3-TTS-12Hz-1.7B-Base` (https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base) voiced
    every shipped line by cloning that reference.

  Both model cards declare `license: apache-2.0` (Hub metadata, re-checked 2026-11-03; the repos
  have no separate LICENSE file). The `qwen-tts` 0.1.1 inference package (PyPI) ships the full
  Apache License 2.0 text. Apache-2.0 permits commercial use and places no restriction on
  generated audio.
- **No real person's voice is used.** The five references `docs/brand/audio/refs/{sad,marki,walk,insaner,brutile}-ref.flac`
  are themselves VoiceDesign outputs (designed from text prompts recorded in `lines.json`).
- **Post-processing** (EQ, de-essing, reverb, WORLD-vocoder layers for marki's growl and insaner's
  demon double, loudness normalisation) is original numpy/scipy code plus ffmpeg 6.1, with the
  `pyworld` 0.3.5 (MIT; wraps the WORLD vocoder) and `pyloudnorm` 0.2.0 (MIT) libraries, used as offline tools;
  nothing from them is embedded in the shipped files.
- **QA only (never shipped, not in the repo):**
  - `Systran/faster-whisper-medium` (MIT): speech recognition / character error rate.
  - `prithivMLmods/Common-Voice-Gender-Detection` (Apache-2.0, wav2vec2): gender plausibility.
  - `JaesungHuh/voice-gender-classifier` (MIT, ECAPA-TDNN): second gender opinion.

## ElevenLabs (evaluated 2026-11-03, nothing shipped)

The owner's ElevenLabs workspace was tried as the primary source. Three designed voices
(model `eleven_ttv_v3`, language `ko`, synthetic: no real person) were saved there:
Brutile `JJkYF9pNQkhiwu5NHBDW`, Sad `xLoQXNclZDKhFgVbxDKw`, Marki `AYuW1wKCb8GXbmSOy9OH`.
Rendering then failed: the workspace is on the free tier (3/3 custom voices; "free generations"
errors), and ElevenLabs disabled free-tier generation for the account. **No ElevenLabs audio is
in this repository.** If it is used later: commercial use of ElevenLabs output requires a paid
plan under ElevenLabs' terms (free-tier output is non-commercial and needs attribution), and
library voices (e.g. "Kang", `8G6jifm9f1BhHXadvwOt`) are real voice actors' voices.
`docs/brand/audio/post_voice.py` already accepts ElevenLabs downloads (`<line-id>_t<k>.mp3`).

## Sound effects (`sfx/*.m4a`)

- Fully synthesized by `docs/brand/audio/gen_sfx.py` (oscillators + seeded noise, numpy/scipy).
  Original work of this project; no samples or third-party sound libraries. This includes the
  shared `death.m4a` and `waste-death.m4a` (a piece dissolving on brutile's wasteland).

## Encoding

AAC-LC in an MP4 container (`.m4a`) via ffmpeg's native `aac` encoder: voice 24 kHz mono 64 kb/s,
SFX 48 kHz mono 64 kb/s. Decodes in Chromium (Android WebView) and Safari/WKWebView.
