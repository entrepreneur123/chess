# Audio sources and licences

Everything under `public/audio/` is generated by the scripts in `docs/brand/audio/`
(see the README there to regenerate). No third-party recordings or sample packs are used.

## Voice lines (`vo/*.m4a`)

- **Speech synthesis:** Qwen3-TTS, model `Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign`
  (https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign). The model card declares
  `license: apache-2.0` (README.md front matter, checked 2026-11-02; the Hugging Face repo has
  no separate LICENSE file). The `qwen-tts` 0.1.1 inference package (PyPI) ships the full
  Apache License 2.0 text (`qwen_tts-0.1.1.dist-info/licenses/LICENSE`).
  Apache-2.0 permits commercial use and places no restriction on generated audio.
- The voices are *designed* from text descriptions (no voice cloning, no real person's voice).
- **Post-processing** (pitch/formant shift, EQ, reverb, growl/bitcrush layers, loudness
  normalisation) was done with original numpy/scipy code plus ffmpeg 6.1 filters
  (`asetrate`, `aresample`, `rubberband`) and the `pyworld`/`pyloudnorm` analysis libraries,
  used as offline tools only; nothing from them is embedded in the shipped files.
- **QA only (not shipped):** `Systran/faster-whisper-medium` (MIT) for the speech-recognition check.

## Sound effects (`sfx/*.m4a`)

- Fully synthesized by `docs/brand/audio/gen_sfx.py` (oscillators + seeded noise, numpy/scipy).
  Original work of this project; no samples or third-party sound libraries.

## Encoding

AAC-LC in an MP4 container (`.m4a`) via ffmpeg's native `aac` encoder: voice 24 kHz mono 48 kb/s,
SFX 48 kHz mono 64 kb/s. Decodes in Chromium (Android WebView) and Safari/WKWebView.
