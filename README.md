# GRID CLASH — 12×12 전술 아레나 (MVP)

3개의 캐릭터로 싸우는 12×12 전략 보드게임. 매칭 전에 진형을 짜고, 봇과 1:1 대전합니다.

## 바로 해보기

```bash
npm install
npm run dev        # http://localhost:5173 (휴대폰에서는 같은 Wi-Fi에서 표시되는 Network 주소로 접속)
```

```bash
npm test           # 엔진/봇/메타 단위 테스트
npm run build      # 타입체크 + 프로덕션 빌드 (dist/)
```

## 게임 규칙

| 항목 | 규칙 |
| --- | --- |
| 보드 | 12×12. 내 말은 아래쪽(파랑), 상대는 위쪽(빨강) |
| 기물 | 진영당 3개. 보유한 캐릭터(사드·마르키·월크·인세이너) 중 3명을 골라 분대 편성, 1–3성 |
| 배치 | 매칭 전, 내 진영 3×12 구역 안에만 배치 |
| 기본 규칙 | 아군 말은 통과/점령 불가, 이동 경로의 첫 적 말은 잡을 수 있음 (체스와 동일) |
| 승리 | 상대 말을 모두 잡으면(또는 자기장이 모두 삼키면) 승리 |
| 시간 | 턴당 45초. 양쪽 중 한쪽이 2개 이하면 40초, 1개 이하면 20초. 초과 시 턴이 넘어가고, 3번 연속 초과하면 기권패 |
| 대전 시간 | 한 판 최대 10분(일시정지 제외). 시간이 다 되면 남은 말 가치 합으로 판정 (같으면 무승부) |
| 자기장 | 한쪽이라도 말이 1개만 남거나, 40수(양측 합계, 서든데스)에 도달하면 발동. 그때부터 6턴(각 3수)마다 좌우 바깥 세로줄이 한 줄씩 자기장이 되어 좁혀오고, 자기장 칸의 말은 즉시 소멸. 자기장으로 이동·통과 불가. 가로로만 좁혀짐 |
| 끝내기 | 서든데스 자기장은 최대 36수 뒤 보드 전체를 덮으므로 한 판은 최대 76수. 양쪽 마지막 말이 같은 자기장에 동시에 사라지면 사라진 말의 가치 합으로 판정 (같으면 무승부) |
| 이동 불가 | 움직일 수 있는 말이 없으면 자동 패스, 양쪽 모두 불가면 가치 합으로 판정 |

### 캐릭터

| 캐릭터 | 등급 | 1성 | 2성 | 3성 |
| --- | --- | --- | --- | --- |
| 사드 | 일반 | 상하좌우 1칸 | 2칸 | 3칸 |
| 마르키 | 희귀 | 앞으로만 3칸 직진 (끝줄에서 방향 전환) | 4칸 | 6칸 |
| 월크 | 영웅 | 바로 앞줄 5칸 중 원하는 칸으로 점프 (끝줄에서 방향 전환) | 7칸 | 9칸 |
| 인세이너 | 전설 | 상하좌우 2칸 | 상하좌우 3칸 | 상하좌우·대각선 3칸 + 적을 잡은 직후 그 말로 한 번 더 이동(턴당 1회, 건너뛰기 가능) |

- 사드·마르키·인세이너는 미끄러지듯 이동해 중간에 말이 있으면 막힙니다.
- 월크는 점프라서 사이에 있는 말을 뛰어넘습니다. 아군 칸에는 못 가고, 적 칸에 가면 잡습니다.
- 인세이너 패시브(흡수): 적을 잡으면 그 말의 캐릭터·성급 이동 패턴을 영구히 흡수해 자기 이동에 더합니다(흡수한 인세이너의 흡수 목록까지 승계). 흡수한 능력은 전력 판정에 절반 가치로 반영됩니다.
- 인세이너는 전설 카드가 처음 나올 때 해금됩니다(상자 전설 확률 3%). 봇은 보통/어려움에서 일정 확률로 인세이너를 데려옵니다.

### 승급 / 경제 (`src/meta/economy.ts`에서 모두 조정 가능)
- 대전 보상 코인: 승리 60/100/150 (쉬움/보통/어려움), 무승부 40, 패배 25
- 상자: 일반 상자 150코인, 하루 1회 무료 상자 → 캐릭터 카드 1–3장 (일반 57% · 희귀 30% · 영웅 10% · 전설 3%)
- 승급: 1성→2성 카드 5장 + 보석 300, 2성→3성 카드 12장 + 보석 900 (보석은 테스트 지급, 결제 없음)
- 유료 결제(보석 팩)는 화면 자리만 있고 실제 결제 기능은 없습니다.

## 구조

```
src/engine/   규칙 엔진 (순수 함수, 불변 상태) — types.ts가 모든 모듈의 공통 규약
src/ai/       봇 (알파베타 탐색) + Web Worker + 클라이언트(실패 시 메인 스레드로 대체)
src/render/   Three.js 3D 보드 + WebGL이 없을 때 쓰는 Canvas2D 보드, 디자인 토큰
src/ui/       라우터, 화면(로비/진형/매칭/게임/캐릭터/상점), GameController 상태 머신
src/meta/     localStorage 프로필(버전/검증/복구), 경제 수치, 봇 상대 생성
src/audio/    합성 효과음(sfx.ts) + 캐릭터 AI 음성·전용 효과음(voice.ts, public/audio/)
tests/        vitest
```

- 대전 화면: 말을 탭하면 이동 가능 칸만 표시(내 말 흰색, 상대 말 빨간색). 상세 정보는 오른쪽 위 ≡ 버튼의 "현재 진형" 패널.
- 캐릭터 음성: Qwen3-TTS(Apache-2.0)로 만든 한국어 대사 41개, 효과음 18개는 직접 합성. 출처·라이선스는 `public/audio/LICENSES.md`, 재생성 방법은 `docs/brand/audio/README.md`.
- 3D 모델 출처·라이선스는 `public/models/LICENSES.md`.

## Android (Google Play) 빌드

Capacitor로 웹 빌드를 감싸 Android 앱으로 만듭니다. Android Studio(SDK)가 설치된 PC에서 실행하세요.

```bash
npx cap add android
```

```bash
npm run cap:sync
```

```bash
npx cap open android
```

Android Studio에서 서명된 AAB(Build › Generate Signed Bundle)를 만들어 Play Console에 업로드합니다.

## MVP에서 정한 가정 (확정 필요)
- 각 진영은 사드·마르키·월크를 1개씩 사용 (중복 불가)
- 월크 "양옆 7칸/9칸"은 앞줄 전체 폭 7칸/9칸(좌우 3/4칸)으로 해석
- 마르키·월크는 앞으로만 가며, 상대 끝줄(또는 되돌아와 내 끝줄)에 도달하면 방향을 바꿔 다시 움직임
- 등급(일반/희귀/영웅)과 말 가치(판정용)는 임시값
- Android 프로젝트 생성 후 `android/app/src/main/AndroidManifest.xml`의 Activity에 `android:screenOrientation="portrait"`를 추가해 세로 고정 권장
