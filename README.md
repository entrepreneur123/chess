# GRID CLASH — 10×10 전술 아레나 (MVP)

3개의 캐릭터로 싸우는 10×10 전략 보드게임. 매칭 전에 진형을 짜고, AI와 1:1 대전합니다. 전장전으로 레이팅을 올려 6개 전장을 오르고, 에센셜로 캐릭터를 영입하고, 던전 토큰으로 성급을 강화합니다.

## 바로 해보기

```bash
npm install
npm run dev        # http://localhost:5173 (휴대폰에서는 같은 Wi-Fi에서 표시되는 Network 주소로 접속)
```

```bash
npm test           # 엔진/봇/메타 단위 테스트
npm run build      # 타입체크 + 프로덕션 빌드 (dist/)
```

## 게임 규칙

| 항목 | 규칙 |
| --- | --- |
| 보드 | 10×10(100칸), 위에서 내려다보는 탑다운 보드(3D 시점은 당분간 비활성). 내 말은 아래쪽(파랑), 상대는 위쪽(빨강) |
| 기물 | 진영당 3개. 보유한 캐릭터 중 3명을 골라 분대 편성(시작 보유: 사드·마르키·월크, 상점 영입: 브루타일·인세이너·미셸·피커·라카엘리), 보유한 성급(1–3성) 이하로 출전 |
| 배치 | 매칭 전, 내 진영 2×10 구역(아래 2줄) 안에만 배치 |
| 기본 규칙 | 아군 말은 통과/점령 불가, 이동 경로의 첫 적 말은 잡을 수 있음 (체스와 동일) |
| 승리 | 상대 말을 모두 잡으면(또는 자기장이 모두 삼키면) 승리 |
| 시간 | 턴당 45초. 양쪽 중 한쪽이 2개 이하면 40초, 1개 이하면 20초. 제한시간을 넘기면 즉시 몰수패 (인세이너 추가 이동을 흘려보내는 것은 몰수 아님) |
| 턴 | 양쪽이 한 수씩 두면 1턴. 화면 위에 현재 턴 수 표시. 전체 대전 시계는 없음 |
| 자기장 | 한쪽이라도 말이 1개만 남거나, 20턴째(각자 19수를 둔 뒤)가 되면 발동. 그때부터 2턴(양쪽이 2수씩 둘 때)마다 좌우 바깥 세로줄이 한 줄씩 자기장이 되어 좁혀옵니다. 3번째 축소(좌우 3줄씩)부터는 위아래 바깥 가로줄도 한 줄씩 함께 좁혀옵니다(3번째: 맨 위·맨 아래 1줄, 4번째: 2줄씩). 자기장 칸의 말은 즉시 소멸, 자기장으로 이동·통과·점프 착지 불가. 자기장은 보드 끝이 아니므로 그 앞에서 방향 전환도 하지 않습니다(앞으로만 가는 말은 자기장을 마주한 채 멈출 수 있음) |
| 끝내기 | 자기장은 5번 좁혀오면(발동 후 최대 20수) 보드 전체를 덮으므로 한 판은 최대 58수(29턴, 인세이너 3성의 추가 이동은 별도). 양쪽 마지막 말이 같은 자기장에 동시에 사라지면 사라진 말의 가치 합으로 판정 (같으면 무승부) |
| 불모지 | 브루타일 스킬로 깔린 땅. 말이 이동하다 불모지에 닿으면(멈추든 지나가든) 그 칸에서 소멸. 미끄러지는 이동(피커의 콩콩 점프 포함)은 불모지 칸에서 끝나고 그 너머로 갈 수 없음 |
| 인형 함정 | 미셸이 남기는 함정. 상대 말이 함정 칸에서 이동을 **마치면** 그 말 주인의 다음 1턴 동안 이동·스킬 불가(속박). 지나가기만 하면 안전(피커만 예외). 함정은 판이 끝날 때까지 남고, 자기 편 함정은 무시. 양쪽 모두에게 보임 |
| 이동 불가 | 움직일 수 있는 말이 없거나 남은 말이 모두 속박이면 자동 패스. 속박이 풀려도 양쪽 모두 움직일 수 없을 때만 가치 합으로 판정 |

### 캐릭터

| 캐릭터 | 등급 | 1성 | 2성 | 3성 |
| --- | --- | --- | --- | --- |
| 사드 | 일반 | 상하좌우 1칸 | 2칸 | 3칸 |
| 마르키 | 희귀 | 앞으로만 3칸 직진 (끝줄에서 방향 전환) | 4칸 | 앞으로 5칸 + 좌우 1칸 |
| 월크 | 영웅 | 바로 앞줄 5칸 중 원하는 칸으로 점프 (끝줄에서 방향 전환) | 7칸 | 9칸 |
| 인세이너 | 전설 | 상하좌우 2칸 | 상하좌우 3칸 | 상하좌우 3칸 + 대각선 1칸 + 적을 잡은 직후 그 말로 한 번 더 이동(턴당 1회, 추가 이동으로 잡아도 연속 추가 이동 없음, 건너뛰기 가능) |
| 브루타일 | 전설 | 앞쪽 좌우 대각선 1칸 (끝줄에서 방향 전환) | + 뒤로 1칸 | 주변 8칸 1칸 |
| 미셸 | 일반 | 좌·우·뒤로 1칸 | 좌·우·뒤로 최대 2칸 | 2성 + 앞으로 1칸 |
| 피커 | 희귀 | 대각선 4방향 1칸 (콩콩) | 최대 2칸 | 최대 3칸 |
| 라카엘리 | 영웅 | 앞줄 3칸(정면·좌우 대각) 점프 (끝줄에서 방향 전환) | 앞 2줄 × 3칸 | 앞 2줄 × 3칸 + 뒤로 1칸 |
| 라카엘리 (타천) | | 앞줄 5칸 | 앞 2줄 × 5칸 | 앞 3줄 × 5칸 + 뒤로 1칸 |

- 사드·마르키·인세이너는 미끄러지듯 이동해 중간에 말이 있으면 막힙니다. 마르키 3성의 좌우 1칸은 방향과 상관없는 보통 1칸 이동입니다(적 칸은 잡기, 아군 칸 불가, 자기장·불모지·함정 규칙 동일).
- 월크는 점프라서 사이에 있는 말을 뛰어넘습니다. 아군 칸에는 못 가고, 적 칸에 가면 잡습니다.
- 인세이너 패시브(흡수): 적을 잡으면 그 말의 캐릭터·성급 **이동 범위만** 영구히 흡수해 자기 이동에 더합니다(특성·스킬은 흡수 안 함, 흡수한 인세이너의 흡수 목록까지 승계). 흡수한 능력은 전력 판정에 절반 가치로 반영됩니다.
- 브루타일 스킬 '불모지': 1성 1칸, 2성 2×2, 3성 3×3의 빈 칸(말이 없는 곳 어디든)을 불모지로 만듭니다. 스킬 사용이 그 턴의 행동입니다. 양쪽이 3수씩 둔 뒤(4턴째)부터 쓸 수 있고 한 판에 1번, 자기장이 좁혀오기 시작하면(첫 축소 이후) 금지. 자기장이 발동하면 축소 전까지 남은 턴을 알려 줍니다.
- 인세이너는 브루타일의 이동은 흡수하지만 불모지 스킬은 흡수하지 않습니다.
- 미셸(앞·뒤는 미셸이 바라보는 방향 기준, 방향 전환 없음): 미끄러지듯 이동하고 도착 칸의 적을 잡습니다. 특성 '인형 함정': 한 판에서 처음 3번 **뒤로** 움직일 때 떠난 칸에 인형 함정을 남깁니다(불모지에서 소멸한 이동은 제외).
- 피커 특성 '콩콩': 대각선 경로의 칸마다 착지하므로 막히지 않습니다. 지나는 칸의 적은 모두 잡고 아군은 뛰어넘으며, 아군 칸에는 착지할 수 없습니다. 상대 인형 함정을 만나면 그 칸에서 멈추고(착지 시 속박), 불모지 칸에 닿으면 그 칸에서 소멸합니다(미끄러지는 이동과 같은 규칙). 자기장 칸은 넘어갈 수 없습니다.
- 인세이너는 미셸의 이동만 흡수하고(함정 특성 제외), 피커를 잡으면 피커 성급의 대각선 범위만 흡수합니다. 흡수한 대각선은 보통 미끄러지는 이동입니다(콩콩 특성 없음: 중간에 말이 있으면 막히고, 도착 칸의 적만 잡으며, 함정은 도착 칸에서만 걸림). 월크의 점프는 이동 방식 자체라 점프로 흡수됩니다. 피커가 여러 말을 한 번에 잡아도 하나의 이동이며, 3성 인세이너는 잡은 뒤 추가 이동 1번, 함정에 걸리면 추가 이동은 없습니다.
- 라카엘리는 월크처럼 점프합니다(사이의 말을 뛰어넘음, 아군 칸 불가, 적 칸은 잡기, 불모지·함정·자기장은 착지 칸 기준). 스킬 '타천': 그 턴의 행동으로 변신하고, 다음 내 2턴 동안 타천 패턴으로 2번 이동한 뒤 원래 모습으로 돌아옵니다(속박으로 쉰 턴도 1번으로 셈, 자기장이 와도 유지). 4턴째부터, 한 판에 1번, 자기장이 좁혀오면 금지, 속박 중·연쇄 이동 중 금지.
- 스킬 사용은 캐릭터마다 한 판에 1번입니다(브루타일과 라카엘리를 함께 내보내면 둘 다 1번씩).
- 인세이너가 라카엘리를 잡으면 라카엘리 성급의 **기본** 패턴만 흡수합니다(타천 패턴·스킬 제외).

### 성장: 레이팅 · 전장 · 재화 (`docs/design/progression.md`, 수치는 `src/meta/progression.ts`)

| 항목 | 규칙 |
| --- | --- |
| 재화 | **토큰**(육각 토큰): 성급 강화에 사용, 던전 보상으로만 획득. **에센셜**: 상점에서 캐릭터 영입에 사용, 전장전·견습전투 승 3 / 무 1 / 패 0 (일일 제한 없음). 그 밖의 재화·상자·실제 결제는 없음 |
| 성급 강화 | 1성→2성 / 2성→3성 토큰: 일반 5/50, 희귀 10/100, 영웅 20/150, 전설 50/300. 강화한 성급까지 골라 출전(낮은 성급 선택 가능) |
| 상점 | 현재 전장 이하에서 열린 미보유 캐릭터 판매: 일반 30, 희귀 50, 영웅 100, 전설 200 에센셜, 1성으로 합류. 강등돼도 보유 캐릭터는 유지 |
| 전장 | 1 달빛 룬 투기장 0–300 · 2 잿불 대장간 301–600(브루타일) · 3 독초 늪 신전 601–1000(인세이너) · 4 서리 성채 1001–1500(미셸) · 5 광기의 왕좌 1501–2000(피커) · 6 천공의 정점 2001+(라카엘리) |
| 레이팅 | 전장전에서만 변동. 시작 전장 기준 승리 +29~31 / +25~29 / +20~22 / +18~22 / +15~17 / +14~16, 패배 −5~7 / −10~14 / −15~17 / −17~20 / −19~21 / −20~22. 무승부 변동 없음, 0 미만 없음, 전장은 레이팅을 따라 자동 승급·강등 |
| 전장전 | 같은 전장 레이팅 ±60 근처 AI. 레이팅·에센셜 |
| 견습전투 | 레이팅 ±150 근처 AI. 레이팅 변동 없음, 에센셜 지급 |
| 던전 | 쉬움 / 보통 / 어려움 / 극악 = 토큰 5 / 10 / 15 / 20. 하루(기기 자정 기준) 첫 **승리**에만 지급, 패배·무승부는 기회 유지. 이후엔 보상 없이 연습 가능. 레이팅·에센셜 없음 |

- **상대는 모두 AI입니다.** 온라인 서버가 아직 없어서 매칭은 레이팅 대역만 흉내 내고, 화면에도 "AI"로 표시합니다.
- AI 분대(전장전·견습전투): 상대 레이팅이 속한 전장까지 열린 캐릭터 중 3명, 성급은 내가 출전한 성급 평균 ±1(1–3), 수읽기는 1 전장 쉬움 · 2–3 보통 · 4–5 어려움 · 6 극악.
- AI 분대(던전): 쉬움 모두 2성, 보통 3성 1명+2성 2명, 어려움 모두 3성·전설 1명 이상, 극악 모두 3성·전설 1명 이상·최강 수읽기(`src/ai/bot.ts`의 `STRENGTH` 표 한 곳에서 조정).
- 프로필(v5)은 보유 성급, 출전 성급, 진형, 토큰·에센셜, 레이팅·최고 레이팅, 던전 수령일, 전적, 설정(배경음악 포함)을 기기(localStorage)에 저장합니다. v3 이하 저장 데이터는 사전 출시 단계라 성장 정보가 초기화됩니다(시작 3명 1성, 재화·레이팅 0). v4 저장 데이터는 그대로 유지하되, 예전 12×12 보드의 3×12 구역에 맞춘 진형(3번째 줄이나 11·12번째 칸에 말이 있는 진형)은 같은 분대의 추천 배치로 초기화되고 '저장 안 됨' 상태가 됩니다(보유 캐릭터가 아니면 시작 3명). 로컬 저장값은 사용자가 수정할 수 있으므로 실제 PvP·랭킹·결제 전에 서버 권한이 필요합니다.

## 구조

```
src/engine/   규칙 엔진 (순수 함수, 불변 상태) — types.ts가 모든 모듈의 공통 규약
src/ai/       봇 (알파베타 탐색) + Web Worker + 클라이언트(실패 시 메인 스레드로 대체)
src/render/   Three.js 3D 보드 + WebGL이 없을 때 쓰는 Canvas2D 보드, 디자인 토큰
src/ui/       라우터, 화면(상점/캐릭터/대전/진형/전장 탭, 매칭, 게임), GameController 상태 머신, 배경음악 브리지(musicBridge.ts)
src/meta/     성장 규칙(progression.ts), localStorage 프로필 v5(버전/검증/복구/정산), 대전 속도 수치, AI 상대 생성
src/audio/    합성 효과음(sfx.ts) + 캐릭터 AI 음성·전용 효과음(voice.ts, public/audio/)
tests/        vitest
```

- 탭: 상점 · 캐릭터 · 대전(가운데) · 진형 · 전장. 탭 화면 위쪽에 레이팅(전장 배지)·토큰·에센셜 표시, 재화를 탭하면 획득 방법 안내.
- 대전 화면: 말을 탭하면 이동 가능 칸만 표시(내 말 흰색, 상대 말 빨간색). 상세 정보는 오른쪽 위 ≡ 버튼의 "현재 진형" 패널.
- 캐릭터 음성: Qwen3-TTS(Apache-2.0)로 만든 한국어 대사 41개, 효과음 18개는 직접 합성. 출처·라이선스는 `public/audio/LICENSES.md`, 재생성 방법은 `docs/brand/audio/README.md`.
- 3D 모델 출처·라이선스는 `public/models/LICENSES.md`.

## Android (Google Play) 빌드

Capacitor로 웹 빌드를 감싸 Android 앱으로 만듭니다. Android Studio(SDK)가 설치된 PC에서 실행하세요.

```bash
npx cap add android
```

```bash
npm run cap:sync
```

```bash
npx cap open android
```

Android Studio에서 서명된 AAB(Build › Generate Signed Bundle)를 만들어 Play Console에 업로드합니다.

## MVP에서 정한 가정 (확정 필요)
- 각 진영은 사드·마르키·월크를 1개씩 사용 (중복 불가)
- 월크 "양옆 7칸/9칸"은 앞줄 전체 폭 7칸/9칸(좌우 3/4칸)으로 해석
- 마르키·월크는 앞으로만 가며, 상대 끝줄(또는 되돌아와 내 끝줄)에 도달하면 방향을 바꿔 다시 움직임
- 등급(일반/희귀/영웅)과 말 가치(판정용)는 임시값
- Android 프로젝트 생성 후 `android/app/src/main/AndroidManifest.xml`의 Activity에 `android:screenOrientation="portrait"`를 추가해 세로 고정 권장
